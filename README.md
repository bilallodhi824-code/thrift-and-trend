## ✨ Features
- **Curated Footwear Catalog:** 12 verified sneaker, running, formal, and boot models with real product photography.
- **Dynamic Filter & Search:** Multi-attribute filtering across category, sizing (EU 38-46), condition grading, and price sorting.
- **Interactive Bag & Checkout:** Full cart drawer, coupon code application (`STYLE20`), and order simulation.
- **Admin Dashboard:** Full product management (Add, Edit, Delete), live inventory counts, order status tracker, and system diagnostics.
- **Customer Authentication:** JWT token authentication with MS SQL Server support for secure user sessions and order history.
- **Zero AI Buzzwords:** Real retail condition grading, authentic sneaker specifications, and transparent consignment stories.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
cd server && npm install && cd ..
```

### 2. Run Development Server
```bash
# Terminal 1: Frontend
npm run dev

# Terminal 2: Backend
cd server && npm run dev
```
